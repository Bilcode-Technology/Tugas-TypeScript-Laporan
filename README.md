Project ini berisi tiga program TypeScript yang dipisah per soal.
Penjelasan baris demi baris kode dan berkas konfigurasi ada di [PENJELASAN.md](PENJELASAN.md).

## Persiapan

Pastikan Node.js dan npm sudah terpasang. Buka terminal di folder project ini, lalu jalankan:

```bash
npm install
```

## Menjalankan program

Jalankan salah satu perintah berikut dari folder project:

```bash
npm run soal1
npm run soal2
npm run soal3
```

## Dasar perhitungan

- **Soal 1:** digit terakhir NIM adalah `2`, sehingga segitiga memiliki 2 baris.
- **Soal 2:** dua digit terakhir adalah `92`; digit ketiga dari belakang adalah `4`, sehingga beda deret adalah `4 + 1 = 5`. Deretnya: `92, 97, 102, 107, 112, 117, 122, 127, 132, 137`.
- **Soal 3:** dua digit terakhir `92` ditambah `10`, sehingga batas pencarian prima adalah `102`.
